# АК БАРС — Система развития

Веб-приложение для тренера по хоккею: карточки игроков, план/факт,
календарь тренировок, отчёты, экспорт в PDF и Excel, шаблоны тренировок.

Работает как **одностраничное приложение (SPA)** на чистом JavaScript
без сборщиков и без ES-модулей — все скрипты подключаются через обычные
`<script>` теги в `index.html`.

---

## Возможности

### Игроки
- Карточка игрока: паспорт, фото, возраст (вычисляется из даты рождения)
- Навыки по 4 разделам: техника, физика, тактика, психология
- Профиль навыков (лепестковая диаграмма) и динамика «начало → конец сезона»
- План развития: цели по навыкам, сроки, комплексы, факт выполнения
- Статистика матчей по клубам и разделам
- Тесты: 6 настраиваемых столбцов + 6 графиков динамики
- Автоматический подсчёт общей оценки (среднее по 4 разделам)

### Календарь тренера
- Месячная сетка Пн–Вс по всем игрокам
- Тренировки с несколькими блоками (комплекс + формат + время + длительность)
- 3 формата работы: Самостоятельная / Индивидуальная с тренером / В группе
- Групповое назначение игроков (один клик — несколько игроков)
- Повтор тренировки на 1–8 недель вперёд по выбранным дням недели
- Отметка факта выполнения (Выполнено / Частично / Не выполнено)
- Комментарий обязателен для «Частично» и «Не выполнено»
- Удаление одной тренировки или всей серии

### Шаблоны тренировок
- Сохранение текущей формы как шаблона (кнопка «💾 Сохранить как шаблон»)
- Быстрое заполнение формы из шаблона (дропдаун «▼ Заполнить из шаблона»)
- Удаление шаблона прямо из дропдауна
- Шаблоны общие для всех сезонов и синхронизируются с облаком

### Справочник упражнений
- 2-уровневое дерево: большие группы → подгруппы → упражнения
- Перемещение подгрупп между большими группами
- Перемещение упражнений между подгруппами
- Порядок элементов (▲ ▼)
- Ссылки на видео для каждого упражнения
- Автоматическая миграция старого плоского формата

### Отчёты
- **Отчёт по игрокам** — за месяц, по каждому игроку, с % выполнения
- **Отчёт тренера** — KPI, тепловая карта нагрузки, 4 графика, активность по игрокам
- Экспорт обоих отчётов в PDF

### Экспорт / импорт
- **PDF**: полная карточка игрока и краткая (без тех/тестов/характеристики)
- **Excel**: экспорт игрока, шаблон для заполнения, импорт игрока из `.xlsx`
- **JSON**: полный бэкап базы (экспорт + импорт)
- **CSV**: массовый импорт игроков

### Сезоны
- Сезон: с 1 июля по 31 мая
- Переключение между сезонами одним кликом
- Создание нового сезона с переносом игроков (выборочно) и структуры навыков
- Данные сезонов изолированы
- Архивный сезон защищён от изменений (можно временно разрешить)
- Автоматический выбор текущего сезона по календарю

### Синхронизация
- Облако на Supabase (авторизация по email + пароль)
- Автосохранение в `localStorage` (мгновенно) и в облако (через 2 сек после изменений)
- Ручная синхронизация, принудительная загрузка / выгрузка
- Индикатор состояния в шапке
- Приоритет локальных данных при конфликте (защита от затирания)
- Работа офлайн — изменения копятся локально и уйдут в облако при подключении

### Уведомления
- Колокольчик в шапке со счётчиком
- Просроченные / сегодняшние / предстоящие тренировки
- Клик по уведомлению — открытие карточки игрока

## Технологии

- **Vanilla JavaScript** — без фреймворков и сборщиков
- **Chart.js 4.4** — графики и радары (CDN)
- **XLSX 0.18** — работа с Excel (CDN)
- **jsPDF 2.5 + html2canvas 1.4** — экспорт в PDF (CDN)
- **Supabase JS 2** — авторизация и хранение данных (CDN)
- **GitHub Pages** — хостинг
